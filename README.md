# Word Serpent

A neon-styled twist on the classic Snake game. Instead of eating generic food, the snake spells out a word you choose — each letter is collected in order until the word is complete.

## How it works

1. Enter any word (2–16 letters, A–Z).
2. The snake starts as the first letter of your word.
3. Letter pellets appear one at a time, in order. Eat them to grow the snake and spell the word.
4. Hit a wall or yourself and it's game over.

## Play

Open `index.html` in any modern browser — no build step, no dependencies.

## Controls

- **Arrow keys** or **WASD** — move
- **Enter** — start / restart
- **On-screen D-pad** — appears automatically on small screens

## Speed

Pick Slow / Normal / Fast / Turbo from the dropdown before pressing Play.
